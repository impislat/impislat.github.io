# YOUNG IMP18 — DIGITAL ARCHIVE v2

Открой `index.html`.

Что добавлено:
- cinematic preloader / intro;
- постоянный glass-player внизу;
- интерактивный треклист CH4NEL;
- локальная аудиосистема: положи MP3 в `assets/audio/` как `ch4nel-01.mp3` ... `ch4nel-17.mp3`;
- album experience modal для релизов;
- крупная editorial-типографика;
- marquee;
- 3D-hover карточек;
- плавные reveal-анимации;
- parallax;
- custom cursor;
- secret mode: пять кликов по IMP18;
- identity/terminal section;
- мобильная версия;
- реальные ссылки на стриминги.

Важно: в текущем архиве MP3 намеренно не добавлены, потому что исходники треков не были переданы. Интерфейс уже готов: после добавления файлов с указанными именами плеер начнёт играть их локально.
